IoT Smart Dustbin System

Learn how to build an automatic smart dustbin that opens its lid using an ultrasonic sensor and a servo motor when someone approaches.

1. Required Components

  • Arduino Uno (or any compatible board)
  • Ultrasonic Sensor (HC-SR04 - հեռավորության սենսոր)
  • Servo Motor (SG90 - կափարիչը շարժելու համար)
  • Jumper Wires (միացնող լարեր)
  • Power Supply / USB Cable

2. Circuit Connections

  • HC-SR04: VCC -> 5V, GND -> GND, Trig -> Pin 9, Echo -> Pin 10
  • Servo Motor: Signal -> Pin 6, VCC -> 5V, GND -> GND

3. Arduino Code (Sketch)

Upload this code to your Arduino board using the Arduino IDE:


#include <Servo.h>

const int trigPin = 9;
const int echoPin = 10;
Servo myServo;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  myServo.attach(6);
  myServo.write(0); // Lid closed position
  Serial.begin(9600);
}

void loop() {
  long duration;
  int distance;

  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duration = pulseIn(echoPin, HIGH);
  distance = duration * 0.034 / 2;

  // If someone is closer than 20 cm
  if (distance > 0 && distance < 20) {
    myServo.write(90); // Open lid
    delay(3000);       // Keep open for 3 seconds
  } else {
    myServo.write(0);  // Close lid
  }

  delay(100);
}

4. Conclusion

By building this smart dustbin, you learned how ultrasonic distance measurement works and how to synchronize it with servo motor motion for everyday automation!
