IoT Smart Plant Watering System

Learn how to build an automated plant watering system using Arduino, a soil moisture sensor, and a mini water pump.

1. Required Components

  • Arduino Uno (or any compatible board)
  • Soil Moisture Sensor (հողի խոնավության սենսոր)
  • Relay Module (5V ռելե՝ պոմպը կառավարելու համար)
  • Mini Water Pump (5V ջրի փոքր պոմպ)
  • Jumper Wires (միացնող լարեր)
  • External Power Supply / Battery

2. Circuit Connections

  • Soil Moisture Sensor: VCC -> 5V, GND -> GND, A0 -> Arduino Analog Pin A0
  • Relay Module: VCC -> 5V, GND -> GND, IN -> Arduino Digital Pin D7
  • Water Pump: Connected through the Relay switch to an external power source.

3. Arduino Code (Sketch)

Upload this code to your Arduino board using the Arduino IDE:


const int sensorPin = A0;  // Soil moisture sensor pin
const int relayPin = 7;    // Relay control pin
const int threshold = 500; // Dry threshold level

void setup() {
  Serial.begin(9600);
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // Turn pump OFF initially
}

void loop() {
  int moistureValue = analogRead(sensorPin);
  Serial.print("Moisture Level: ");
  Serial.println(moistureValue);

  if (moistureValue > threshold) {
    Serial.println("Soil is dry! Watering plants...");
    digitalWrite(relayPin, LOW);  // Turn pump ON
    delay(5000);                  // Water for 5 seconds
    digitalWrite(relayPin, HIGH); // Turn pump OFF
  }

  delay(300000); // Check every 5 minutes
}

4. Conclusion

By completing this project, you’ve learned the basics of reading analog sensor data and controlling high-power devices safely using a relay module with Arduino!
