IoT Smart Home Automation System

Learn how to build a basic smart home system using Arduino, a temperature sensor, and automated lighting control.

1. Required Components

  • Arduino Uno (or any compatible board)
  • DHT11 Temperature & Humidity Sensor
  • Relay Module (for controlling appliances / lights)
  • LEDs & Resistors
  • Jumper Wires & Breadboard

2. Circuit Connections

  • DHT11 Sensor: VCC -> 5V, GND -> GND, Data -> Digital Pin 2
  • Relay Module: VCC -> 5V, GND -> GND, IN -> Digital Pin 7
  • LEDs: Connected to digital pins for room status simulation.

3. Arduino Code (Sketch)

Upload this code to your Arduino board using the Arduino IDE:


#include <DHT.h>

#define DHTPIN 2     // Digital pin connected to the DHT sensor
#define DHTTYPE DHT11 // DHT 11
const int relayPin = 7;

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
  pinMode(relayPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // Off initially
}

void loop() {
  delay(2000);
  float h = dht.readHumidity();
  float t = dht.readTemperature();

  if (isnan(h) || isnan(t)) {
    Serial.println(F("Failed to read from DHT sensor!"));
    return;
  }

  Serial.print(F("Humidity: "));
  Serial.print(h);
  Serial.print(F("%  Temperature: "));
  Serial.print(t);
  Serial.println(F("°C"));

  // If temperature is high, turn on cooling/fan via relay
  if (t > 25.0) {
    digitalWrite(relayPin, LOW); // Turn on relay/fan
    Serial.println("Temperature high! Fan ON.");
  } else {
    digitalWrite(relayPin, HIGH); // Turn off relay/fan
    Serial.println("Temperature normal. Fan OFF.");
  }
}

4. Conclusion

By building this smart home setup, you learned how to read environmental data from sensors and automate home devices based on real-time conditions!
